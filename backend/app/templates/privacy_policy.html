Privacy Policy

This policy describes how {{ project_info.application_name }} processes information within the active deployment.

Version: {{ project_info.version }} Environment: {{ project_info.environment }}

1. Application Data

The application stores information required to operate the video-production workflow, including administrator account details, video-job settings, scripts, scene plans, progress records, generated media references, and output-file locations.

2. API Credentials

API credentials entered through the integrations page are encrypted before being saved. Existing credentials are not displayed in readable form through the dashboard.

3. Generated Content

Scripts, narration, captions, scene assets, and rendered videos are stored within the configured deployment storage. Their retention depends on the server administrator's backup, deletion, and storage policies.

4. External Providers

When configured, the application may send production-related requests to external AI, media, publishing, or infrastructure providers. Those services process information according to their own terms and privacy policies.

5. Authentication and Sessions

Access to protected dashboard pages requires an authenticated administrator session. Session information is used to maintain secure access to the application.

6. Server Logs

The operating system, application service, and supporting infrastructure may record technical logs such as request details, errors, service status, and processing events for monitoring and troubleshooting.

7. Data Control

The deployment administrator is responsible for controlling user access, server security, backups, retention periods, generated files, and configured third-party integrations.

8. Google and YouTube User Data

Atta Video AI uses Google OAuth to allow users to connect their own YouTube channels. The application requests only the Google permissions required for its YouTube publishing features.

The YouTube read-only permission is used to identify and display information about the connected YouTube channel. The YouTube upload permission is used to upload videos to that channel when the authorized user requests or configures a publishing action.

The application may store the connected channel identifier, channel information required by the application, and OAuth credentials required to maintain the connection. OAuth access and refresh tokens are encrypted before being stored.

Google user data is used only to provide the user-facing YouTube connection and publishing functionality requested by the user. Google user data is not sold, used for advertising, transferred to data brokers, used for credit decisions, or used to train artificial-intelligence models.

Google user data is not disclosed to third parties except where necessary to provide the requested application functionality, maintain security, comply with applicable law, or where the user has explicitly authorized the disclosure.

The application uses HTTPS for network communication and encryption for stored OAuth credentials. Access to administrative application functions is protected by authentication.

OAuth credentials are retained while a YouTube connection remains active and is required for the requested functionality. When a channel is disconnected through Atta Video AI, its stored access and refresh tokens are removed from the active connection. Users may also revoke access through their Google Account.

9. Contact

Questions about this application can be submitted through attarasool.com.

This page provides general application information and should be reviewed and adapted by the deployment owner for applicable legal and business requirements.
